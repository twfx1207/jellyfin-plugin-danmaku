常规

首次安装后需要重启 Jellyfin，并对网页执行一次强制刷新。
优先使用文件前 16 MiB 的 MD5；未精确命中时使用 TMDB、标题与集数搜索，并且只自动采用唯一结果。

弹弹play

本插件接入弹弹play开放弹幕网络。 请在其开发者中心申请 AppId 与 AppSecret；密钥只由 Jellyfin 服务端使用，不会发送到浏览器。

自定义 HTTP 源

插件会以 GET 查询参数传递 itemId、title、seriesName、season、episode、tmdbId、fileName、fileSize、duration、query 与 automatic。
使用 {episodeId} 作为所选节目编号占位符。
匹配响应格式：{"isMatched":false,"matches":[{"episodeId":"1","animeTitle":"标题","episodeTitle":"第1集","shift":0}]}； 弹幕响应格式：{"comments":[{"time":12.3,"mode":1,"color":16777215,"text":"内容"}]}。

显示与缓存

作为尚未单独设置过的 Web 播放器默认值。
Web 播放器中的速度倍率以此时长为 1.0×。
